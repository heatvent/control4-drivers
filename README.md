# Control4 Drivers

Free, open-source Control4 DriverWorks drivers by **Heatvent (with Claude)**.

| Driver | Device | Control | Latest |
|---|---|---|---|
| [GoFanco Matrix44-HDBT](gofanco-matrix44-hdbt/) | gofanco Matrix44-HDBT 4x4 HDMI 2.0 HDBaseT matrix (G4-0064B) | RS-232 or IP (TCP) | 3.2.2 |

## Installing a driver

1. Download the `.c4z` file from the driver's folder.
2. In Composer Pro, choose **Driver → Add or Update Driver** and select the file.
3. Follow the setup steps in that driver's README.

## Disclaimer

These drivers are unofficial. The device manufacturers and Snap One/Control4 did not make them and don't support them. Use them at your own risk, and back up your project before installing or replacing drivers. Manufacturer names and logos are trademarks of their owners and are used only to identify the devices each driver controls.
